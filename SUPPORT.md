# Support

Use GitHub Discussions or an issue for installation questions, reproducible bugs,
and proposed capabilities. Before filing a report, search existing issues and run
the smallest relevant example.

A useful support request includes:

- LMX commit/version and installation method;
- Python, JAX, jaxlib, platform, device, and precision policy;
- complete command or minimal Python/TOML case;
- expected and observed behavior;
- traceback, solver status, residuals, and relevant balance diagnostics;
- whether the complete portable test gate passes.

Do not include credentials, proprietary geometry/data, or personal information in
a public issue. Security vulnerabilities belong in the private process described
in [SECURITY.md](SECURITY.md).

Research-stage features are supported on a best-effort basis and carry no claim
beyond their documented evidence envelope. Scientific collaboration, custom
validation campaigns, and materials qualification require separate coordination;
an issue is not a guarantee of analysis, turnaround time, or endorsement.
